BigData Sandbox

Un cluster de Big Data entero en una imagen de Docker: HDFS, YARN, MapReduce, Hive, Spark, Pig, Sqoop con MySQL, ZooKeeper y MongoDB, cada uno como un proceso aparte, con la arquitectura que elijas. Cada versión tiene su mapa interactivo (qué hay, cómo se usa y cómo se conecta cada cosa), su README y su guía paso a paso.

El cluster: Hadoop 3.3.6, Hive 4.0 sobre Tez, Spark 3.5, Pig, Sqoop con MySQL, ZooKeeper y MongoDB. Es también latest y el archivo del aula.

Arrancar

docker run -d --name bigdata --stop-timeout 20 \
  -e DATANODES=3 -e REPLICATION=2 -e BLOCK_SIZE=1m -e MONGODB=si \
  -p 127.0.0.1:9870:9870 -p 127.0.0.1:9868:9868 -p 127.0.0.1:9901-9909:9901-9909 \
  -p 127.0.0.1:8088:8088 -p 127.0.0.1:8042:8042 -p 127.0.0.1:19888:19888 \
  -p 127.0.0.1:10000:10000 -p 127.0.0.1:10002:10002 \
  -p 127.0.0.1:18080:18080 -p 127.0.0.1:4040:4040 \
  -p 127.0.0.1:3306:3306 -p 127.0.0.1:27017:27017 \
  -v bigdata_hadoop:/hadoop -v "$(pwd)/datos:/datos" \
  franki678/bigdata-sandbox:base
